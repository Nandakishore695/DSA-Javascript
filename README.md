# DSA-Javascript

- DSA stands for Data Structures and Algorithms.
- It’s a fundamental concept in computer science and programming that focuses on how data is organized, stored, and processed efficiently.

- What is Data Structure?
- Way to organize data so that we can use this data efficiently.
- Example:-[8,2,6,3,4,7,0] - [0,2,3,4,6,7,8]

- What is Algoritham?
- Steps or a process to arrange data.
